Maxi-Schedule-Generator

Maxi is a command line schedule generator that builds a flexible personal day from a person's age, habits, current situation, sleep and wake times, and a chosen adaptability level, and it deliberately avoids micromanaging the hours it proposes. This site is the sharpener's order book: the day is entered in the order the work will actually happen.

The day is shaped around the sleeper first and the tasks second: wake and sleep times anchor everything else. All answers and the generated schedule are saved to a document titled scheduleai.txt, unless you pick a different output file with --output.

Page two: the method, worked as a grit sequence

Coarse pass. The non negotiable blocks are fixed first: sleep, work or study, meals. Meals are placed adaptively or at fixed times, as the intake answered.

Middle pass. Flexible activities are arranged in the gaps: habits and a health block woven between focus blocks, breaks following the chosen style, pomodoro 25 and 5, flowmodoro 50 and 10, or one large break.

Fine pass. Transitions are smoothed and breathing room is left. The adaptability score sets how much buffer sits between blocks, and Maxi leaves slack on purpose rather than packing every minute. A 30 minute wind down block closes the day at the sleep time, and sleep times at or before the wake time are treated as the next day.

Page three: a worked example day, on an order slip

07:00Wake. The day opens here, not at the first task.
07:30Breakfast, placed adaptively.
08:00Focus block, pomodoro cycles of 25 and 5.
10:00Intentional space. Nothing is scheduled here on purpose.

12:30Lunch.
14:00Focus block, with a health block woven in.
18:00Dinner.
19:00Intentional space, kept empty by the fine pass.
22:30Wind down, 30 minutes, closing at the sleep time of 23:00.

An illustration of the shape Maxi builds from the rules above, not a captured run. The generated day is a guide with slack built in, not an order to be obeyed minute by minute.

Closing page: running Maxi locally

Requires Python 3 only: standard library, nothing to install, no API key.

python3 main.py
python3 main.py --answers answers.txt
python3 main.py --answers answers.txt --output my-schedule.txt

The answers file holds one key: value line per factor (keys: age, habits, situation, wake, sleep, adaptability, health, conflicts, adaptive_eating, break_style, template). A template file lists your own blocks, one per line as minutes | label, and replaces the built in block sequence; template lines with a duration of zero or less are skipped. Run python3 main.py --help for the full option list.

Input Maxi cannot use gets a short error message and exit 1, never a traceback: a time that is not HH:MM in 24 hour time or is out of range, an unknown break style, an invalid template number, a missing or non UTF 8 answers file, an unreadable template path, and an output path that cannot be written. Ending the interview early with EOF or Ctrl-C also exits 1, and no schedule file is written. Two answers are read leniently on purpose: an adaptability value outside 0 to 10 is clamped to that range, and a non numeric adaptability falls back to 5.

Tests: python3 -m unittest runs 21 tests in test_main.py, covering time parsing, the three break styles, schedule building, the answers file reader, and the command line paths.
